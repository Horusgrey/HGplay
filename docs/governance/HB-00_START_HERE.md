# MISSION

Build a compliance-first unclaimed-property recovery operating system that
converts verified public records into transparent owner assistance, documented
claims, and measurable outcomes without losing control of data, legal
eligibility, or product truth.

# CURRENT PHASE

Prototype consolidation and compliance correction. The existing project proves
the workflow concept, but it is not production-ready.

# DEFINITION OF DONE

1. Every active record is traceable to a verified state source.
2. Paid-service eligibility is checked before outreach or agreement generation.
3. Approved outreach makes the free state-claim option unmistakable.
4. The CRM records consent, contact history, suppression status, agreement
   status, filing status, and payment status.
5. Production code has authentication, access controls, encrypted secrets,
   backups, audit logs, and tested recovery.
6. One canonical release exists. Old builds are archived, not quietly reused.
